Rings of numbers

Quadratic integer rings

Adjoin a square root to the whole numbers and arithmetic changes. Sometimes primes still factor uniquely; sometimes 6 factors in two different ways. Ideals repair the damage, and the class group measures it.

The rings

Let ddd be a square-free whole number other than 1. The quadratic integers for ddd are the numbers a+bωa + b\omegaa+bω with a,ba, ba,b whole numbers, where

ω=d  if d≡2,3(mod4),ω=1+d2  if d≡1(mod4). \omega = \sqrt d \ \text{ if } d \equiv 2, 3 \pmod 4, \qquad \omega = \frac{1 + \sqrt d}{2} \ \text{ if } d \equiv 1 \pmod 4 . ω=d​  if d≡2,3(mod4),ω=21+d​​  if d≡1(mod4).

(The halves are allowed in the second case because ω\omegaω then satisfies ω2−ω+1−d4=0\omega^2 - \omega + \tfrac{1 - d}{4} = 0ω2−ω+41−d​=0, with whole-number coefficients.) They form a ring, the ring of integers of the field Q(d)\mathbb Q(\sqrt d)Q(d​). For d=−1d = -1d=−1 it is the Gaussian integers Z[i]\mathbb Z[i]Z[i], and for d=−3d = -3d=−3 the Eisenstein integers.

The conjugate of x+ydx + y\sqrt dx+yd​ is x−ydx - y\sqrt dx−yd​, and the norm is the product of the two, a whole number:

N(x+yd)=x2−dy2,N(αβ)=N(α) N(β). N(x + y\sqrt d) = x^2 - d y^2, \qquad N(\alpha\beta) = N(\alpha)\,N(\beta). N(x+yd​)=x2−dy2,N(αβ)=N(α)N(β). 
import { quadraticRing, gaussianIntegers } from "@ratmath/structures";

const K = quadraticRing(-5);
String(K);                       // "Z[√−5]"
const a = K.sqrt(1, 1);          // 1 + √−5
String(a.mul(a));                // "−4 + 2√−5"
a.norm();                        // 6n
String(a.conj());                // "1 − √−5"
String(quadraticRing(5).omega);  // "(1 + √5)/2": the golden ratio

Units

An element is a unit exactly when its norm is ±1\pm 1±1. For d<0d < 0d<0 there are only finitely many: ±1\pm 1±1, except the four powers of iii when d=−1d = -1d=−1 and the six sixth roots of unity when d=−3d = -3d=−3. For d>0d > 0d>0 there are infinitely many, all of the form ±εk\pm\varepsilon^k±εk for one fundamental unit ε>1\varepsilon > 1ε>1. Finding it is solving Pell's equation x2−dy2=±1x^2 - d y^2 = \pm 1x2−dy2=±1 (or ±4\pm 4±4), and the continued fraction of d\sqrt dd​ does it. The fundamental unit can be surprisingly large.

String(quadraticRing(2).fundamentalUnit);     // "1 + √2", norm −1
String(quadraticRing(7).fundamentalUnit);     // "8 + 3√7":  8² − 7·3² = 1
String(quadraticRing(61).fundamentalUnit);    // "(39 + 5√61)/2"
String(quadraticRing(94).fundamentalUnit);    // "2143295 + 221064√94"
gaussianIntegers().units.list.map(String);    // ["1", "i", "−1", "−i"]

Division with remainder

In the Gaussian integers one can divide with a remainder of smaller norm: compute the exact quotient in Q(i)\mathbb Q(i)Q(i) and round both coordinates. So Euclid's algorithm works, greatest common divisors exist, and factorisation into primes is unique, exactly as for whole numbers. The same holds in a handful of other rings (for example d=−2,−3,−7,−11,2,3,5,13d = -2, -3, -7, -11, 2, 3, 5, 13d=−2,−3,−7,−11,2,3,5,13), called norm-Euclidean.

const G = gaussianIntegers();
const { quotient, remainder } = G.divmod(G.of(27, 23), G.of(8, 1));
[String(quotient), String(remainder)];        // ["4 + 2i", "−3 + 3i"]: norm 18 is less than 65
String(G.gcd(G.of(11, 3), G.of(1, 8)).gcd);   // "2 + i"

const f = G.factor(2210);
f.factors.map(({ prime, exponent }) => `${prime}${exponent > 1 ? "^" + exponent : ""}`);
      // ["1 + i^2", "2 − i", "2 + i", "3 + 2i", "3 − 2i", "4 − i", "4 + i"]: 2210 = 2·5·13·17

A whole-number prime ppp behaves in one of three ways in the ring. It can stay prime (inert), become a product of two different primes (split), or become the square of a prime, up to a unit (ramified). In Z[i]\mathbb Z[i]Z[i]: 2 ramifies, primes p≡1(mod4)p \equiv 1 \pmod 4p≡1(mod4) split (that is Fermat's theorem that such a prime is a sum of two squares), and primes p≡3(mod4)p \equiv 3 \pmod 4p≡3(mod4) are inert.

When unique factorisation fails

An element is irreducible when it is not a product of two non-units. It is prime when it cannot divide a product without dividing a factor. For whole numbers these are the same thing. In Z[−5]\mathbb Z[\sqrt{-5}]Z[−5​] they are not:

6=2⋅3=(1+−5)(1−−5). 6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5}). 6=2⋅3=(1+−5​)(1−−5​).

All four factors are irreducible, since their norms are 4, 9, 6, 6 and no element has norm 2 or 3 (x2+5y2x^2 + 5y^2x2+5y2 never equals 2 or 3). But none is prime: 2 divides the product on the right without dividing either factor. So 6 has two genuinely different factorisations.

K.factorizations(6).map((f) => f.factors.map(String));
      // [["2", "3"], ["1 + √−5", "1 − √−5"]]
K.isIrreducible(2);              // true
K.isPrimeElement(2);             // false
K.elementsOfNorm(2);             // []
K.isUFD;                         // false

Ideals put it right

Kummer and Dedekind's repair: factor ideals, not elements. In these rings every nonzero ideal is a product of prime ideals in exactly one way. The two factorisations of 6 are two ways of grouping the same four prime ideals:

⟨2⟩=p2,⟨3⟩=q qˉ,⟨1+−5⟩=p q,⟨1−−5⟩=p qˉ, \langle 2\rangle = \mathfrak p^2, \quad \langle 3\rangle = \mathfrak q\,\bar{\mathfrak q}, \quad \langle 1 + \sqrt{-5}\rangle = \mathfrak p\,\mathfrak q, \quad \langle 1 - \sqrt{-5}\rangle = \mathfrak p\,\bar{\mathfrak q}, ⟨2⟩=p2,⟨3⟩=qqˉ​,⟨1+−5​⟩=pq,⟨1−−5​⟩=pqˉ​,

with p=⟨2,1+−5⟩\mathfrak p = \langle 2, 1 + \sqrt{-5}\ranglep=⟨2,1+−5​⟩ and q=⟨3,1+−5⟩\mathfrak q = \langle 3, 1 + \sqrt{-5}\rangleq=⟨3,1+−5​⟩. None of p,q,qˉ\mathfrak p, \mathfrak q, \bar{\mathfrak q}p,q,qˉ​ is generated by a single element, which is why they were invisible among the numbers.

const p = K.ideal(2, a);                 // (2, 1 + √−5)
const q = K.ideal(3, a);
p.norm;                                  // 2n: the quotient by p has 2 elements
p.isPrime();                             // true
p.isPrincipal();                         // false
String(p.mul(p));                        // "(2)"
String(p.mul(q));                        // "(1 + √−5)"
String(p.mul(q).generator());            // "1 + √−5"
K.ideal(6).factor().map(({ prime, exponent }) => `${prime}^${exponent}`);
      // ["(2, 1 + √−5)^2", "(3, 2 + √−5)^1", "(3, 1 + √−5)^1"]
K.splitting(7).kind;                     // "split"

The class group

How badly does unique factorisation fail? Call two ideals equivalent when one is the other multiplied by a number of the field. The classes form a finite abelian group under multiplication, the class group, and its size hhh is the class number. The principal ideals are the identity class, so

h=1  ⟺  every ideal is principal  ⟺  factorisation of elements is unique. h = 1 \iff \text{every ideal is principal} \iff \text{factorisation of elements is unique}. h=1⟺every ideal is principal⟺factorisation of elements is unique.

The class group is computable because every class contains an ideal of norm at most the Minkowski bound (2π∣D∣\tfrac{2}{\pi}\sqrt{|D|}π2​∣D∣​ for an imaginary ring and 12D\tfrac12\sqrt D21​D​ for a real one, where DDD is the discriminant). So it is enough to look at the primes above the small whole-number primes and work out which products are principal.

K.classNumber();                              // 2
p.isEquivalentTo(q);                          // true: both are in the one non-principal class
quadraticRing(-23).classGroup().text;         // "C3"
quadraticRing(-65).classGroup().text;         // "C2 × C4"
quadraticRing(10).classNumber();              // 2: 6 = 2·3 = (4 + √10)(4 − √10)
[-1, -2, -3, -7, -11, -19, -43, -67, -163].map((d) => quadraticRing(d).classNumber());
      // all 1, and by the Baker–Heegner–Stark theorem no other negative d has class number 1
quadraticRing(-19).isPID;                     // true, although
quadraticRing(-19).isNormEuclidean;           // false

Class groups are found by listing ideals up to the Minkowski bound and testing which are principal, which suits discriminants up to a few thousand. Whether there are infinitely many real quadratic rings of class number 1 is an open problem.
