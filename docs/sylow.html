Sylow subgroups

Lagrange's theorem says what sizes a subgroup cannot have. Sylow's theorems go the other way: for the largest power of each prime dividing the order, a subgroup of that size always exists, and the number of them is tightly constrained.

The theorems

Write ∣G∣=pam|G| = p^a m∣G∣=pam with ppp a prime not dividing mmm. A subgroup of order pap^apa is a Sylow p-subgroup. Sylow's theorems say:

  1. Sylow p-subgroups exist.
  2. Any two of them are conjugate, and every subgroup of ppp-power order lies inside one.
  3. Their number npn_pnp​ divides mmm and satisfies np≡1(modp)n_p \equiv 1 \pmod pnp​≡1(modp).

Since they are all conjugate, np=[G:N(P)]n_p = [G : N(P)]np​=[G:N(P)] for any one of them PPP, where N(P)={g:gPg−1=P}N(P) = \{g : gPg^{-1} = P\}N(P)={g:gPg−1=P} is its normaliser. In particular a Sylow subgroup is normal exactly when np=1n_p = 1np​=1.

How one is found

sylowSubgroup(p) grows a ppp-subgroup one step at a time. Start with P=1P = 1P=1. While ∣P∣<pa|P| < p^a∣P∣<pa, the quotient N(P)/PN(P)/PN(P)/P has order divisible by ppp (this is the heart of the proof of the first theorem), so by Cauchy's theorem it has an element of order ppp. Any x∈N(P)x \in N(P)x∈N(P) whose image in N(P)/PN(P)/PN(P)/P has ppp-power order makes ⟨P,x⟩=P⟨x⟩\langle P, x \rangle = P\langle x\rangle⟨P,x⟩=P⟨x⟩ a bigger ppp-group. When ∣P∣=pa|P| = p^a∣P∣=pa it is a Sylow subgroup, and its conjugates are all the others. The tests compare npn_pnp​ found this way with a count of all subgroups of order pap^apa, for every prime and every test group up to order 168.

import { alternating, symmetric, GL, PSL, identify } from "@ratmath/structures";

const A = alternating(5);                  // |A5| = 60 = 2²·3·5
[2, 3, 5].map((p) => A.sylowCount(p));    // [5, 10, 6]
identify(A.sylowSubgroup(2)).name;         // "C2 × C2"

const S = symmetric(4);
identify(S.sylowSubgroup(2)).name;         // "D4"
S.sylowSubgroups(3).length;                // 4

const G = GL(2, 3);
identify(G.sylowSubgroup(2)).name;         // "SD16", the semidihedral group
[2, 3, 7].map((p) => PSL(2, 7).sylowCount(p));   // [21, 28, 8]

Using the theorems

The counting condition alone often pins a group down. If ∣G∣=15|G| = 15∣G∣=15 then n3n_3n3​ divides 5 and is 1 mod 3, so n3=1n_3 = 1n3​=1; likewise n5n_5n5​ divides 3 and is 1 mod 5, so n5=1n_5 = 1n5​=1. Both Sylow subgroups are normal, they meet only in eee, and G≅C3×C5≅C15G \cong C_3 \times C_5 \cong C_{15}G≅C3​×C5​≅C15​: every group of order 15 is cyclic. The same argument works for pqpqpq with primes p<qp < qp<q and p∤q−1p \nmid q - 1p∤q−1.

For order 12, n3n_3n3​ is 1 or 4. In A4A_4A4​ it is 4, so there are 4×2=84 \times 2 = 84×2=8 elements of order 3, leaving room for just one subgroup of order 4: n2=1n_2 = 1n2​=1. A simple group of order 60 must have n5=6n_5 = 6n5​=6, which forces 24 elements of order 5; A5A_5A5​ is one, and it is the only one.
