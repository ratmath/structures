Groups

Character tables

A representation turns the elements of a group into matrices. Its character keeps only the traces, and astonishingly that is enough: a small square table of numbers, one row per irreducible representation and one column per conjugacy class, determines how every representation of the group breaks up. Here the table is computed exactly for any group the library can list.

Representations and characters

A representation of GGG of degree ddd is a homomorphism ρ:G→GLd(C)\rho : G \to GL_d(\mathbb{C})ρ:G→GLd​(C). Its character is χ(g)=tr⁡ρ(g)\chi(g) = \operatorname{tr}\rho(g)χ(g)=trρ(g). Since conjugate matrices have equal traces, χ\chiχ is constant on conjugacy classes, and χ(1)=d\chi(1) = dχ(1)=d. A representation is irreducible if no proper subspace is preserved by every ρ(g)\rho(g)ρ(g); every representation is a direct sum of irreducible ones (Maschke), so every character is a sum of irreducible characters. The basic facts:

  • there are exactly as many irreducible characters as conjugacy classes;
  • their degrees divide ∣G∣|G|∣G∣ and satisfy ∑χχ(1)2=∣G∣\sum_\chi \chi(1)^2 = |G|∑χ​χ(1)2=∣G∣;
  • a representation is determined up to isomorphism by its character.

Because ggg has finite order nnn, the matrix ρ(g)\rho(g)ρ(g) is diagonalisable with nnn-th roots of unity as eigenvalues. So χ(g)\chi(g)χ(g) is a sum of χ(1)\chi(1)χ(1) roots of unity: an algebraic integer in the cyclotomic field Q(ζn)\mathbb{Q}(\zeta_n)Q(ζn​). That is why the entries of a table are things like −1-1−1, iii, 1+52\frac{1+\sqrt5}{2}21+5​​ or ζ73\zeta_7^3ζ73​, and why they can be held exactly.

import { characterTable, symmetric, alternating } from "@ratmath/structures";

const T = characterTable(alternating(5));
console.log(String(T));
//       1a  2a  3a          5a          5b
// size   1  15  20          12          12
// χ₁     1   1   1           1           1
// χ₂     3  −1   0  (1 + √5)/2  (1 − √5)/2
// χ₃     3  −1   0  (1 − √5)/2  (1 + √5)/2
// χ₄     4   0   1          −1          −1
// χ₅     5   1  −1           0           0

T.degrees;                        // [1, 3, 3, 4, 5]:  1 + 9 + 9 + 16 + 25 = 60
T.classes[3];                     // { name: "5a", size: 12, order: 5, centralizerOrder: 5, representative, … }
T.irreducibles[1].values[3];      // a Cyclotomic: (1 + √5)/2, exactly

Classes are named by the order of their elements and a letter. Characters are listed by degree with the trivial character first.

Orthogonality

Class functions have an inner product

⟨χ,ψ⟩=1∣G∣∑g∈Gχ(g) ψ(g)‾, \langle \chi, \psi \rangle = \frac{1}{|G|} \sum_{g \in G} \chi(g)\,\overline{\psi(g)} , ⟨χ,ψ⟩=∣G∣1​g∈G∑​χ(g)ψ(g)​,

and the irreducible characters are an orthonormal basis for it: ⟨χi,χj⟩=δij\langle \chi_i, \chi_j \rangle = \delta_{ij}⟨χi​,χj​⟩=δij​. The columns are orthogonal too: for elements g,hg, hg,h,

∑χχ(g) χ(h)‾={∣CG(g)∣if g,h are conjugate,0otherwise. \sum_{\chi} \chi(g)\,\overline{\chi(h)} = \begin{cases} |C_G(g)| & \text{if } g, h \text{ are conjugate,} \\ 0 & \text{otherwise.} \end{cases} χ∑​χ(g)χ(h)​={∣CG​(g)∣0​if g,h are conjugate,otherwise.​

verify() checks both relations and the degree sum on the exact values. Every table is verified this way before it is returned, so a wrong table cannot come out quietly.

How the table is found

Nobody constructs the matrices. The method is Burnside's, made practical by Dixon and Schneider. Let C1,…,CrC_1, \dots, C_rC1​,…,Cr​ be the classes and write Ci^\widehat{C_i}Ci​​ for the sum of the elements of CiC_iCi​ in the group algebra. These sums multiply among themselves,

Ci^ Cj^=∑kaijk Ck^,aijk=#{(x,y)∈Ci×Cj:xy=gk}, \widehat{C_i}\,\widehat{C_j} = \sum_k a_{ijk}\,\widehat{C_k}, \qquad a_{ijk} = \#\{(x, y) \in C_i \times C_j : xy = g_k\}, Ci​​Cj​​=k∑​aijk​Ck​​,aijk​=#{(x,y)∈Ci​×Cj​:xy=gk​},

and the whole numbers aijka_{ijk}aijk​ can be counted from the multiplication. In an irreducible representation each class sum acts as a scalar ωχ(Ci)=∣Ci∣ χ(gi)/χ(1)\omega_\chi(C_i) = |C_i|\,\chi(g_i)/\chi(1)ωχ​(Ci​)=∣Ci​∣χ(gi​)/χ(1) (Schur's lemma), so the vector (ωχ(Ck))k(\omega_\chi(C_k))_k(ωχ​(Ck​))k​ is a common eigenvector of the matrices Mj=(aijk)i,kM_j = (a_{ijk})_{i,k}Mj​=(aijk​)i,k​. There are rrr such vectors and they are the only common eigenvectors: find them and the table follows.

Dixon's idea was to do the linear algebra in a finite field. Let eee be the exponent of GGG and choose a prime p≡1(mode)p \equiv 1 \pmod ep≡1(mode) with p>2∣G∣p > 2\sqrt{|G|}p>2∣G∣​. Then GF(p)\mathrm{GF}(p)GF(p) contains the eee-th roots of unity, the eigenvectors can be found there with no rounding, and the degree χ(1)<p/2\chi(1) < p/2χ(1)<p/2 is recovered from ⟨χ,χ⟩=1\langle\chi,\chi\rangle = 1⟨χ,χ⟩=1. To get back from GF(p)\mathrm{GF}(p)GF(p) to genuine cyclotomic numbers: χ(g)\chi(g)χ(g) is ∑kmkζnk\sum_k m_k \zeta_n^k∑k​mk​ζnk​ where mkm_kmk​ counts how often ζnk\zeta_n^kζnk​ is an eigenvalue of ρ(g)\rho(g)ρ(g), and a discrete Fourier transform over the powers of ggg gives

mk=1n∑l=0n−1χ(gl) ζn−kl. m_k = \frac{1}{n} \sum_{l=0}^{n-1} \chi(g^l)\,\zeta_n^{-kl} . mk​=n1​l=0∑n−1​χ(gl)ζn−kl​.

This is a whole number between 0 and χ(1)\chi(1)χ(1), so knowing it mod ppp is knowing it. describe() reports the field and the prime used.

const S = characterTable(symmetric(5));
S.describe();     // "S5 of order 120: 7 classes, degrees 1, 1, 4, 4, 5, 5, 6; values in Q(ζ₆₀), found mod 61"
S.verify();       // { rows: true, columns: true, degrees: true, ok: true }

Reading the group from its table

The kernel of a character is {g:χ(g)=χ(1)}\{g : \chi(g) = \chi(1)\}{g:χ(g)=χ(1)}, a normal subgroup, and every normal subgroup is an intersection of kernels of irreducible characters. So the table shows all normal subgroups and their orders, and in particular whether the group is simple. The number of characters of degree 1 is the index of the commutator subgroup, and the classes of size 1 make up the centre.

const T4 = characterTable(symmetric(4));
T4.normalSubgroups().map((N) => N.order);   // [1, 4, 12, 24]
T4.irreducibles[2].kernel().order;           // 4: the Klein four-group is the kernel of the degree 2 character
T4.abelianizationOrder;                      // 2
characterTable(alternating(5)).isSimple;     // true

The table does not determine the group: the dihedral group D4D_4D4​ and the quaternion group Q8Q_8Q8​ have the same one. They are told apart by the Frobenius–Schur indicator, which needs to know which class the squares fall in.

Cyclotomic numbers

Entries are Cyclotomic values: exact elements of Q(ζn)\mathbb{Q}(\zeta_n)Q(ζn​) with arithmetic, complex and Galois conjugates, and a float approximation. They print as whole numbers when they are, as a+bdc\frac{a + b\sqrt d}{c}ca+bd​​ when they lie in a quadratic field, and otherwise in powers of ζm\zeta_mζm​ for the smallest mmm that works.

import { Cyclotomic } from "@ratmath/structures";
const z = Cyclotomic.root(5);                // ζ₅
String(z.add(z.conj()));                     // "(−1 + √5)/2", which is 2cos(72°)
String(Cyclotomic.root(8).add(Cyclotomic.root(8, 3)));   // "i√2"
z.add(z.conj()).conductor;                   // 5

Tables are computed for groups with up to 400 classes. The cost grows with the number of classes and with the exponent of the group: S7S_7S7​ takes a tenth of a second, M11M_{11}M11​ about a second.
