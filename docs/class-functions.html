Groups

Working with characters

Once the irreducible characters are known, questions about representations become arithmetic on rows of numbers. How does a tensor product break up? What does a permutation action contain? What happens when a representation is restricted to a subgroup, or built up from one? Each is an inner product away.

Decomposing a character

If ψ\psiψ is the character of any representation, the irreducible χi\chi_iχi​ occurs in it exactly ⟨ψ,χi⟩\langle \psi, \chi_i \rangle⟨ψ,χi​⟩ times, by orthonormality. So ψ=∑i⟨ψ,χi⟩ χi\psi = \sum_i \langle\psi,\chi_i\rangle\,\chi_iψ=∑i​⟨ψ,χi​⟩χi​, and ⟨ψ,ψ⟩=∑mi2\langle \psi, \psi \rangle = \sum m_i^2⟨ψ,ψ⟩=∑mi2​ tells at a glance how complicated ψ\psiψ is: it is irreducible exactly when this is 1.

import { characterTable, symmetric } from "@ratmath/structures";

const T = characterTable(symmetric(4));
const [triv, sign, two, std, other] = T.irreducibles;     // degrees 1, 1, 2, 3, 3

T.regular.multiplicities();          // [1, 1, 2, 3, 3]: each irreducible occurs as often as its degree
const psi = T.classFunction([4, 0, 2, 1, 0]);             // values on the classes 1a, 2a, 2b, 3a, 4a
psi.norm;                            // 2
psi.decomposition();                 // "χ₁ + χ₄"

Products and squares

The tensor product of two representations has character χψ\chi\psiχψ, the product of values. The square χ2\chi^2χ2 splits further into a symmetric and an alternating part with characters

S2χ(g)=12(χ(g)2+χ(g2)),Λ2χ(g)=12(χ(g)2−χ(g2)). S^2\chi(g) = \tfrac12\bigl(\chi(g)^2 + \chi(g^2)\bigr), \qquad \Lambda^2\chi(g) = \tfrac12\bigl(\chi(g)^2 - \chi(g^2)\bigr). S2χ(g)=21​(χ(g)2+χ(g2)),Λ2χ(g)=21​(χ(g)2−χ(g2)).

These need the power map, which says in which class the squares of each class lie; T.powerMap(k) gives it for any power, and chi.adams(k) is the class function g↦χ(gk)g \mapsto \chi(g^k)g↦χ(gk).

std.mul(sign).equals(other);         // true: twisting by the sign swaps the two characters of degree 3
std.mul(std).decomposition();        // "χ₁ + χ₃ + χ₄ + χ₅"
std.symmetricSquare().decomposition();   // "χ₁ + χ₃ + χ₄"
std.alternatingSquare().decomposition(); // "χ₅"

Real, complex and quaternionic

The Frobenius–Schur indicator of an irreducible character is

ι(χ)=1∣G∣∑g∈Gχ(g2)∈{1,0,−1}. \iota(\chi) = \frac{1}{|G|} \sum_{g \in G} \chi(g^2) \in \{1, 0, -1\}. ι(χ)=∣G∣1​g∈G∑​χ(g2)∈{1,0,−1}.

It is 1 when the representation can be written with real matrices, 0 when the character is not real-valued, and −1-1−1 when the character is real but the representation is not (it is then quaternionic). The quaternion group's character of degree 2 has indicator −1-1−1; the dihedral group's has +1+1+1, though the two tables agree entry for entry. Also ∑χι(χ)χ(1)\sum_\chi \iota(\chi)\chi(1)∑χ​ι(χ)χ(1) counts the solutions of x2=1x^2 = 1x2=1.

characterTable(quaternion()).irreducibles[4].indicator();   // −1
characterTable(dihedral(4)).irreducibles[4].indicator();    //  1
characterTable(quaternion()).irreducibles[4].type;          // "quaternionic"

Restriction and induction

A character of GGG restricts to a character of any subgroup HHH. In the other direction, a character φ\varphiφ of HHH induces a character of GGG of degree [G:H] φ(1)[G:H]\,\varphi(1)[G:H]φ(1):

Ind⁡HGφ (g)=1∣H∣∑x∈G,  xgx−1∈Hφ(xgx−1). \operatorname{Ind}_H^G\varphi\,(g) = \frac{1}{|H|} \sum_{x \in G,\; xgx^{-1} \in H} \varphi(xgx^{-1}) . IndHG​φ(g)=∣H∣1​x∈G,xgx−1∈H∑​φ(xgx−1).

Frobenius reciprocity ties the two together: ⟨Ind⁡φ,χ⟩G=⟨φ,Res⁡χ⟩H\langle \operatorname{Ind}\varphi, \chi\rangle_G = \langle \varphi, \operatorname{Res}\chi\rangle_H⟨Indφ,χ⟩G​=⟨φ,Resχ⟩H​.

const G = symmetric(4);
const H = G.sylowSubgroup(2);                // a dihedral group of order 8
const TH = characterTable(H);

std.restrict(H).decomposition();             // in H's own characters
TH.irreducibles[4].induce(T).decomposition();   // "χ₄ + χ₅": degree 2·3 = 6
TH.irreducibles[4].induce(T).inner(std) === std.restrict(TH).inner(TH.irreducibles[4]);   // true

Permutation characters

When GGG acts on a finite set, the permutation matrices give a representation whose character counts fixed points. By the orbit-counting lemma, ⟨π,χ1⟩\langle \pi, \chi_1 \rangle⟨π,χ1​⟩ is the number of orbits. And ⟨π,π⟩\langle \pi, \pi \rangle⟨π,π⟩ is the number of orbits on pairs, so a transitive action is doubly transitive exactly when π=χ1+χ\pi = \chi_1 + \chiπ=χ1​+χ with χ\chiχ irreducible. The action on the cosets of HHH has character Ind⁡HG1\operatorname{Ind}_H^G 1IndHG​1.

import { action } from "@ratmath/structures";
const X = action(G, [0, 1, 2, 3], (g, x) => g[x]);
const pi = T.permutationCharacter(X);
pi.values.map(String);               // ["4", "0", "2", "1", "0"]
pi.decomposition();                  // "χ₁ + χ₄": doubly transitive
T.permutationCharacter(H).decomposition();   // "χ₁ + χ₃": the action on the three cosets of H
