Automorphisms and the Galois correspondence

The symmetries of a field extension form a group, and when the extension has as many symmetries as its degree allows, the subgroups of that group match the fields in between, one for one and upside down. Here both sides are computed and laid next to each other.

Automorphisms

An automorphism of KKK is a bijection σ:K→K\sigma : K \to Kσ:K→K respecting sums and products. It must fix every rational number, and it must send a root of a rational polynomial to a root of the same polynomial, because f(σ(x))=σ(f(x))=0f(\sigma(x)) = \sigma(f(x)) = 0f(σ(x))=σ(f(x))=0. So an automorphism of Q(θ)\mathbb{Q}(\theta)Q(θ) is determined by where it sends θ\thetaθ, and the choices are exactly the roots of the minimal polynomial of θ\thetaθ that lie in the field. That is how they are found: the tower is rewritten on a primitive element, its minimal polynomial is factored over the field itself, and each linear factor is an automorphism.

import { extension, identify } from "@ratmath/structures";

const L = extension({ a: "a^2 - 2", b: "b^2 - 3" });
L.automorphisms().map(String);
// ["a ↦ a, b ↦ b", "a ↦ −a, b ↦ −b", "a ↦ a, b ↦ −b", "a ↦ −a, b ↦ b"]

const s = L.automorphisms()[2];
String(s.apply(L.of("a + b + a b")));   // "−ab + a − b"

Galois extensions

There are never more automorphisms than the degree. When there are exactly [K:Q][K : \mathbb{Q}][K:Q] of them the extension is Galois, and the group of automorphisms is its Galois group Gal(K/Q)\mathrm{Gal}(K/\mathbb{Q})Gal(K/Q). Equivalently, KKK is the splitting field of a polynomial: it is generated by all the roots of something. The field Q(23)\mathbb{Q}(\sqrt[3]{2})Q(32​) is not Galois, since the other two cube roots of 2 are not real and so not in it; adjoining a cube root of unity www repairs that.

extension({ c: "c^3 - 2" }).isGalois;                  // false: only the identity
const S = extension({ c: "c^3 - 2", w: "w^2 + w + 1" });
S.isGalois;                                            // true
identify(S.galoisGroup()).name;                        // "S3"

galoisGroup() returns an ordinary finite group of the library, whose elements are the automorphisms, so its subgroups, classes and quotients are all available.

The correspondence

For a subgroup HHH of the Galois group, the elements of KKK fixed by everything in HHH form a field KHK^HKH. For a field FFF between Q\mathbb{Q}Q and KKK, the automorphisms fixing FFF pointwise form a subgroup. The fundamental theorem of Galois theory says that for a Galois extension these two maps are inverse to each other, and:

  • bigger subgroups fix smaller fields, with [KH:Q]=[G:H][K^H : \mathbb{Q}] = [G : H][KH:Q]=[G:H];
  • KHK^HKH is itself Galois over Q\mathbb{Q}Q exactly when HHH is a normal subgroup, and then its Galois group is G/HG/HG/H.

A fixed field is a null space: σ(x)=x\sigma(x) = xσ(x)=x is a set of linear equations on the coordinates of xxx. fixedField solves them, then looks for a single generator, trying sums and products of the conjugates of basis elements first so that the answer is recognisable.

const G = S.galoisGroup();
for (const H of [...G.subgroups()].sort((x, y) => x.order - y.order)) {
  const F = S.fixedField([...H.elements]);
  console.log(H.order, G.isNormal(H), F.degree, String(F.generator), F.text);
}
// 1 true  6 "c + w"   x⁶ + 3x⁵ + 6x⁴ + 3x³ + 9x + 9
// 2 false 3 "cw + c"  x³ + 2
// 2 false 3 "−cw"     x³ + 2
// 2 false 3 "c"       x³ − 2
// 3 true  2 "w"       x² + x + 1
// 6 true  1 "1"       x − 1

The three subgroups of order 2 are conjugate and not normal, and they fix the three cubic fields Q(c)\mathbb{Q}(c)Q(c), Q(cw)\mathbb{Q}(cw)Q(cw), Q(cw2)\mathbb{Q}(cw^2)Q(cw2), none of which is Galois. The normal subgroup of order 3 fixes Q(w)\mathbb{Q}(w)Q(w), which is.

Galois groups of polynomials

The Galois group of a polynomial is the Galois group of its splitting field, acting on the roots. Building the splitting field as a tower is one way to get it, but its degree can be as large as n!n!n!. For a polynomial of degree up to 7 the group is found far faster from the roots themselves, by @ratmath/algebraic; that is what solving by radicals starts from.
