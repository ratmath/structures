Reference

Everything in the library

Every export of @ratmath/structures: groups first, then polynomials, ideals and rings of numbers. Group elements are given by value or by their printed label. Coefficients handed back to you are Core Rationals over Q, and the field's own elements otherwise. Wherever a polynomial is expected, text or a number is accepted too.

Errors

Bad input throws a RangeError or TypeError with a message that names the problem: a variable the ring does not have, an inexact division, a field that cannot decide whether a coefficient is zero, a factoring job too large for the method.
