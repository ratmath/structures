Groups

Conjugacy classes and commutators

Two elements are conjugate when one is the other seen from a different point of view. Sorting a group into conjugacy classes, and measuring how far it is from commutative, are the first two ways to see its shape.

Conjugacy

Elements \(x\) and \(y\) of \(G\) are conjugate when \(y = gxg^{-1}\) for some \(g \in G\). This splits the group into conjugacy classes. In \(S_n\) two permutations are conjugate exactly when they have the same cycle type, so the classes of \(S_n\) correspond to the partitions of \(n\): \(S_5\) has 7 of them. In a matrix group, conjugate matrices are similar matrices.

The centraliser \(C(x) = \{g : gx = xg\}\) is a subgroup, and the elements \(gxg^{-1}\) are in one-to-one correspondence with the cosets of \(C(x)\). So

\[ |\text{class of } x| = [G : C(x)] = \frac{|G|}{|C(x)|}, \]

and every class size divides \(|G|\). The centre \(Z(G)\), the elements commuting with everything, is made of the classes of size 1. Adding up the classes gives the class equation

\[ |G| = |Z(G)| + \sum_i [G : C(x_i)], \]

one term for each class of size more than 1.

import { alternating, dihedral, symmetric, cycleString } from "@ratmath/structures";

const A = alternating(4);
A.conjugacyClasses().map((c) => `${cycleString(c.representative)}: ${c.size}`);
// ["(): 1", "(1 3)(2 4): 3", "(1 2 3): 4", "(1 2 4): 4"]
String(A.classEquation());          // "12 = 1 + 3 + 4 + 4"

const D = dihedral(4);
String(D.classEquation());          // "8 = 2 + 2 + 2 + 2"
D.centre().elements.map((x) => D.format(x));      // ["e", "r²"]
D.centraliser("r").order;           // 4

symmetric(5).conjugacyClasses().length;   // 7, the partitions of 5

The class equation has quick consequences. If \(|G| = p^k\) for a prime \(p\), every term on the right but \(|Z(G)|\) is a multiple of \(p\), so \(p\) divides \(|Z(G)|\): a group of prime-power order has a nontrivial centre. It also shows that \(A_4\) has no subgroup of order 6: such a subgroup would have index 2, so it would be normal, so it would be a union of classes including \(\{e\}\). The class sizes are 1, 3, 4 and 4, and no choice of them containing the 1 adds up to 6 (see subgroups).

Commutators

The commutator of \(a\) and \(b\) is \([a, b] = a^{-1}b^{-1}ab\). It is \(e\) exactly when \(a\) and \(b\) commute. The commutator subgroup (or derived subgroup) \(G' = [G, G]\) is the subgroup generated by all commutators. It is normal, and it is the smallest normal subgroup whose quotient \(G/G'\) is abelian. The library computes it as the smallest normal subgroup containing the commutators of the generators, which is the same subgroup.

import { dihedral, symmetric, alternating, GL, SL } from "@ratmath/structures";

const D = dihedral(4);
D.format(D.commutator("r", "s"));   // "r²"
D.derivedSubgroup().order;          // 2

symmetric(4).derivedSubgroup().equals(alternating(4));   // true
GL(2, 3).derivedSubgroup().equals(SL(2, 3));             // true
alternating(5).isPerfect;          // true: A5 is its own commutator subgroup

Solvable and nilpotent groups

Repeating the commutator subgroup gives the derived series \(G \supseteq G' \supseteq G'' \supseteq \cdots\). The group is solvable when this reaches the trivial group. The name comes from Galois theory: a polynomial can be solved by radicals exactly when its Galois group is solvable, and \(S_5\) is not, which is why there is no formula for the quintic.

Two other series measure how close a group is to abelian. The lower central series \(\gamma_1 = G\), \(\gamma_{i+1} = [\gamma_i, G]\), and the upper central series \(Z_0 = 1\), \(Z_{i+1}/Z_i = Z(G/Z_i)\). The group is nilpotent when the lower series reaches 1 (equivalently, the upper series reaches \(G\)), and the number of steps is its nilpotency class. Abelian groups have class 1; every group of prime-power order is nilpotent; every nilpotent group is solvable.

import { symmetric, heisenberg, dihedral } from "@ratmath/structures";

symmetric(4).derivedSeries().map((H) => H.order);     // [24, 12, 4, 1]: solvable
symmetric(5).isSolvable;                              // false
symmetric(4).isNilpotent;                             // false
heisenberg(3).lowerCentralSeries().map((H) => H.order);   // [27, 3, 1]
heisenberg(3).nilpotencyClass;                        // 2
dihedral(8).nilpotencyClass;                          // 3
