Chain complexes and homology

Homology turns a space built from cells into a list of abelian groups. Once the cells and their boundaries are written down, everything is integer linear algebra: the Smith normal form of each boundary matrix gives the free part and the torsion.

Chain complexes

A cell complex has \(n_k\) cells in dimension \(k\). The chain group \(C_k = \mathbb Z^{n_k}\) has one generator per \(k\)-cell, and the boundary map \(\partial_k : C_k \to C_{k-1}\) sends a cell to the signed sum of the cells on its boundary. The boundary of a boundary is empty, so \(\partial_{k-1}\partial_k = 0\), and the cycles \(\ker \partial_k\) contain the boundaries \(\operatorname{im}\partial_{k+1}\). The homology is the quotient

\[ H_k = \ker \partial_k \,/\, \operatorname{im} \partial_{k+1}. \]

chainComplex takes the list \([\partial_1, \partial_2, \dots]\). Each \(\partial_k\) has one column per \(k\)-cell holding its boundary, and one row per \((k-1)\)-cell. It checks \(\partial\partial = 0\) and refuses a list that is not a chain complex.

import { chainComplex } from "@ratmath/structures";

// The torus: one vertex v, edges a, b, one face glued along a b a⁻¹ b⁻¹.
// ∂a = v − v = 0, ∂b = 0, ∂(face) = a + b − a − b = 0.
const T = chainComplex([[[0, 0]], [[0], [0]]]);
String(T);                 // "H0 = Z, H1 = Z^2, H2 = Z"
T.eulerCharacteristic;     // 0 = 1 − 2 + 1

// The projective plane: face glued along a a, so ∂(face) = 2a.
const P = chainComplex([[[0]], [[2]]]);
String(P);                 // "H0 = Z, H1 = Z/2, H2 = 0"

Homology from the Smith normal form

Invertible integer row and column operations bring \(\partial_k\) to the diagonal form \(\operatorname{diag}(d_1, \dots, d_{r_k}, 0, \dots)\) with \(d_1 \mid d_2 \mid \cdots\) (see abelian groups). Then \(\ker\partial_k\) is free of rank \(n_k - r_k\), and inside it \(\operatorname{im}\partial_{k+1}\) is spanned by \(d_i e_i\) for the invariant factors of \(\partial_{k+1}\). So

\[ H_k \cong \mathbb Z^{\,n_k - r_k - r_{k+1}} \oplus \bigoplus_{d_i > 1} \mathbb Z/d_i, \]

where the \(d_i\) are those of \(\partial_{k+1}\). For the Klein bottle, glued along \(a b a^{-1} b\), \(\partial_2 = 2b\) and \(H_1 = \mathbb Z \oplus \mathbb Z/2\).

const K = chainComplex([[[0, 0]], [[0], [2]]]);
String(K.homology(1));          // "Z/2 × Z"
chainComplex([[[0, 0]], [[2, 6], [4, 8]]]).homology(1).toString();   // "Z/2 × Z/4": Smith form diag(2, 4)

Betti numbers, χ and other coefficients

The Betti number \(b_k\) is the rank of \(H_k\), the number of copies of \(\mathbb Z\). Over a field the same recipe gives a vector space: over \(\mathbb Q\) its dimension is \(b_k\), and over \(\mathbb Z/p\) the ranks are counted mod \(p\), so torsion divisible by \(p\) shows up twice (the universal coefficient theorem: \(\dim H_k(\mathbb Z/p) = b_k + t_k + t_{k-1}\), with \(t_k\) the number of invariant factors of \(H_k\) divisible by \(p\)). In every case the alternating sum of Betti numbers is the Euler characteristic \(\chi = \sum (-1)^k n_k\), which needs no homology at all.

P.betti();                              // [1, 0, 0]
P.betti({ coefficients: "Z/2" });       // [1, 1, 1]: the Z/2 in H1 is counted in H1 and in H2
String(P.homology(2, { coefficients: "Z/2" }));   // "Z/2"
P.eulerCharacteristic;                  // 1
