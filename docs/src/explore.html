An exact calculator for everything in the library. Type an expression and press Enter (Shift+Enter for a new line). Letters are variables, numbers are exact, and name = … keeps a value for later lines.

Click an entry to edit it again.
How to write things

Variables are single letters, and the ring is made from the letters you use. Products can be written side by side: 3xy^2, (x + 1)(x - 1). Fractions and decimals are exact. Rows of a matrix are separated by ; as in det(a, b; c, d). order lex (or grlex, grevlex) changes how terms are ordered and how division runs. groebner, member, eliminate, radical and solve take a list of polynomials (each set to zero); zmod(n), crt(a, m, b, n), quadratic(d) and qfactor(d, x, y) (which factors x + y√d) work with whole numbers. A kept name such as f can be used in later lines: factor(f), gcd(f, diff(f, x)).

Groups

Type a group's name to see its order, classes, subgroups, Sylow counts and more, with the Cayley table for groups of order up to 24. Names: C6, D4 (the square, order 8), Dic3, Q8, Q16, V4, S4, A5, GL(2,3), SL(2,5), PSL(2,7), Heis(3), SmallGroup(16,4) (the 4th group of order 16 in this library's list), and products such as S3 × C2 (or S3 x C2).
