Sylow subgroups

Lagrange's theorem says what sizes a subgroup cannot have. Sylow's theorems go the other way: for the largest power of each prime dividing the order, a subgroup of that size always exists, and the number of them is tightly constrained.

The theorems

Write \(|G| = p^a m\) with \(p\) a prime not dividing \(m\). A subgroup of order \(p^a\) is a Sylow p-subgroup. Sylow's theorems say:

  1. Sylow p-subgroups exist.
  2. Any two of them are conjugate, and every subgroup of \(p\)-power order lies inside one.
  3. Their number \(n_p\) divides \(m\) and satisfies \(n_p \equiv 1 \pmod p\).

Since they are all conjugate, \(n_p = [G : N(P)]\) for any one of them \(P\), where \(N(P) = \{g : gPg^{-1} = P\}\) is its normaliser. In particular a Sylow subgroup is normal exactly when \(n_p = 1\).

How one is found

sylowSubgroup(p) grows a \(p\)-subgroup one step at a time. Start with \(P = 1\). While \(|P| < p^a\), the quotient \(N(P)/P\) has order divisible by \(p\) (this is the heart of the proof of the first theorem), so by Cauchy's theorem it has an element of order \(p\). Any \(x \in N(P)\) whose image in \(N(P)/P\) has \(p\)-power order makes \(\langle P, x \rangle = P\langle x\rangle\) a bigger \(p\)-group. When \(|P| = p^a\) it is a Sylow subgroup, and its conjugates are all the others. The tests compare \(n_p\) found this way with a count of all subgroups of order \(p^a\), for every prime and every test group up to order 168.

import { alternating, symmetric, GL, PSL, identify } from "@ratmath/structures";

const A = alternating(5);                  // |A5| = 60 = 2²·3·5
[2, 3, 5].map((p) => A.sylowCount(p));    // [5, 10, 6]
identify(A.sylowSubgroup(2)).name;         // "C2 × C2"

const S = symmetric(4);
identify(S.sylowSubgroup(2)).name;         // "D4"
S.sylowSubgroups(3).length;                // 4

const G = GL(2, 3);
identify(G.sylowSubgroup(2)).name;         // "SD16", the semidihedral group
[2, 3, 7].map((p) => PSL(2, 7).sylowCount(p));   // [21, 28, 8]

Using the theorems

The counting condition alone often pins a group down. If \(|G| = 15\) then \(n_3\) divides 5 and is 1 mod 3, so \(n_3 = 1\); likewise \(n_5\) divides 3 and is 1 mod 5, so \(n_5 = 1\). Both Sylow subgroups are normal, they meet only in \(e\), and \(G \cong C_3 \times C_5 \cong C_{15}\): every group of order 15 is cyclic. The same argument works for \(pq\) with primes \(p < q\) and \(p \nmid q - 1\).

For order 12, \(n_3\) is 1 or 4. In \(A_4\) it is 4, so there are \(4 \times 2 = 8\) elements of order 3, leaving room for just one subgroup of order 4: \(n_2 = 1\). A simple group of order 60 must have \(n_5 = 6\), which forces 24 elements of order 5; \(A_5\) is one, and it is the only one.
